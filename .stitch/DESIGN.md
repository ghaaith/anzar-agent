# AI Software Engineer Agent — Tech Dark Design System

## Visual Theme & Atmosphere

A futuristic, high-contrast dark theme inspired by developer tools like Cursor, Linear, and Vercel. Deep near-black backgrounds with electric blue and purple accents create a premium, technical aesthetic. Glassmorphism effects and subtle glows give depth without distraction. The interface feels powerful, intelligent, and focused — built for engineers who spend hours looking at screens.

## Color Palette & Roles

- **Background (#0A0A0B):** Deep near-black canvas, the foundation of all screens
- **Surface (#18181B):** Dark gray cards, panels, and containers
- **Surface Elevated (#27272A):** Hover states, dropdowns, elevated elements
- **Border (#3F3F46):** Subtle separators and dividers
- **Primary Electric Blue (#3B82F6):** Main CTAs, links, active states, progress indicators
- **Secondary Purple (#8B5CF6):** AI/agent indicators, badges, accent highlights
- **Tertiary Cyan (#06B6D4):** Code syntax accents, secondary highlights
- **Success Green (#22C55E):** Successful operations, positive states
- **Warning Amber (#F59E0B):** Caution states, pending operations
- **Error Red (#EF4444):** Errors, destructive actions, critical alerts
- **Text Primary (#FAFAFA):** Headings and primary content
- **Text Secondary (#A1A1AA):** Labels, descriptions, metadata
- **Text Muted (#71717A):** Disabled states, placeholder text

## Typography Rules

- **Headlines:** Space Grotesk — geometric, tech-forward, slightly condensed
- **Body & Labels:** Inter — exceptional readability at all sizes, neutral and systematic
- **Code:** Monospaced font for all code blocks and terminal output
- **Weight usage:** Medium (500) for labels, Semi-Bold (600) for headlines, Bold (700) for display text
- **Letter-spacing:** Slightly tighter for large headlines to keep them cohesive

## Component Stylings

- **Buttons:** Pill-shaped primary with electric blue fill, ghost variants with subtle borders, micro-interaction hover effects
- **Cards/Containers:** 8px rounded corners, surface color (#18181B), whisper-soft shadows, subtle border
- **Inputs:** 8px rounded, dark background with border, electric blue focus ring with glow
- **Code Blocks:** Darker surface (#0F0F11) with syntax highlighting, monospaced font, line numbers
- **Navigation:** Glassmorphism sidebar with translucent dark background and blur effect
- **Chat Messages:** Alternating subtle surface tones, code blocks inline, agent indicators in purple
- **Status badges:** Pill-shaped with semantic colors, 10% opacity background tint

## Layout Principles

- **Dark-first:** All backgrounds are deep dark, content pops forward with high contrast
- **Generous whitespace:** Breathing room between elements, avoid visual clutter
- **Grid system:** 12-column grid for desktop, 4-column for mobile
- **Panel-based:** Split views with resizable panels for power users
- **Hierarchy through elevation:** Use tonal shifts and subtle shadows, not heavy borders
- **Sticky headers:** Navigation stays visible during scroll
- **Responsive breakpoints:** Mobile (640px), Tablet (768px), Desktop (1024px), Wide (1280px)
